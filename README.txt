OUR LITTLE MEMORY JAR — URL PER TREASURE

The jar starts EMPTY in this version. Add any star, heart, rose, or chocolate using the buttons.
A form asks for a title, message, and URL. After clicking “Add to the jar”, that item appears in the jar.
Click any item, then click “Open this memory” to navigate to the exact URL entered for that item.
Each treasure has its own URL, so different stars can open different websites.

Upload index.html, styles.css, and script.js together to the root of your GitHub Pages repository, replacing older versions.
Memories are saved in localStorage on the current browser/device; they do not sync across devices automatically.
